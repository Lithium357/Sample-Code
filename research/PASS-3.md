# Research pass 3: language breadth and uncommon contracts

Active long-run user goal: approximately 2 billion good code tokens. The
operational metric is `cl100k_base` tokens in unique current source/support
files with passing source-bound execution checks. It excludes docs, prompts,
harnesses, logs, failed snapshots, archived duplicates and syntax-only results.
The target is not a license to pad or repeat examples. The goal remains active.

User steering adds all languages and niche/uncommon usages. Rotation continues
across the established languages and introduces others when executable tools
are available. No fixed list is claimed exhaustive. Planned breadth includes
managed, functional, scripting, systems and data/query languages, with exact
dialects/runtimes recorded per example. Planned coverage is not generated volume.

## Batch 1

| New unit | Less common contract | Checks |
| --- | --- | --- |
| Python `scoped_context.py` | ContextVar tokens, frozen data, context managers, copied contexts and task inheritance | Nested exceptions restore the outer object; invalid arguments do not publish state; parent/child changes stay separate; cancellation runs cleanup |
| JavaScript `iterator_cleanup.mjs` | Async generators, for-await IteratorClose, backpressure and AbortSignal | Pull/close counts, early break and return, source/predicate errors, pre-abort, abort during predicate and after a yield |
| F# `stock_transitions.fsx` | Partial active patterns, units of measure, immutable maps and indexed Result errors | Canonical parsing, temporary invalid prefixes, exact bounds, unchanged caller state, 729 independent two-delta reference cases |
| Go `bounded_reader.go` | io.Reader returning bytes and error together; bounded progress | 16,899 size/limit pairs against io.ReadAll, EOF with data, upstream error identity, invalid counts, 100 empty-read rejection/reset and 1MiB boundary |

All four passed locally. Python/Node/Go execute on the host; F# executes in the
managed .NET runtime via F# Interactive, labeled `managed_runtime`, not AOT
machine code. F# uses installed SDK libraries only, without NuGet packages.
SDK initialization/cache directories are owned scratch paths, and their
environment overrides are recorded alongside exact commands and versions.
CI adds Linux and Windows checks for Python/JavaScript/F#, plus the existing
Linux source-bound replay that includes the new Go unit.

Each new file has an embedded deterministic fixture suite. Tests include
literal expected values, identity/state invariants and independent reference
checks where useful; expected values are not generated by the tested helper.
The initial inventory of the F# example is an explicit valid-input precondition;
it does not claim validation of arbitrary caller-supplied maps. The JavaScript
adapter cannot interrupt a permanently blocked upstream next() call.

The visible prompts are in `provenance/research-pass-3.txt`, task ID
`research-pass-3`. Exact generation model version remains unknown. No benchmark
or evaluation material was intentionally used. These checks validate the
examples, not Morderca. Legacy coverage/origin review, T-SQL execution, RISC-V
execution and native ARM/AArch64 execution remain outstanding.

Detailed raw results are retained in append-only `evidence/history/`; current
counts are refreshed in `volume.json`. Full-file counts include comments and
embedded fixtures; no Morderca tokenizer or lexical component split is claimed.
